# 1.1版本内容模块

本目录只存放1.1剧本专属内容，不放通用经济、军事、外交或政治规则。

- `story_texts.py`：从1.1策划文档读取并渲染故事文本。
- `events.py`：事件注册、触发条件和开局事件链。
- `events_3.py`、`events_4.py`：后续剧情阶段的事件及选择效果。
- `decisions.py`：决议统一入口和首批决议。
- `decisions_3.py`、`decisions_4.py`：后续剧情阶段解锁的决议。
- `strategies.py`：1.1经略定义、前置关系、互斥关系及结算效果。

通用规则仍位于 `app/rules/`；未来1.2内容应放进相邻的 `app/content/v1_2/`，不要直接修改本目录来替换1.1。
