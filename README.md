# 南国魂（测试版）

这是根据《南北朝背景游戏.docx》实现的 Python/Tkinter 桌面策略游戏原型。“金戈铁马”下包含1.1“宋武北伐”和1.2“元嘉之治”两个相互隔离的子剧本，共用地图、基础人物与通用军事/外交框架。

## 启动

需要 Python 3.10 或更新版本。Tkinter 通常随 Windows Python 一起安装。

```powershell
cd game
python -m pip install -r requirements.txt
python main.py
```

本机已有 Pillow 时，可直接运行 `python main.py`。程序优先读取 `game/assets/map.png`，不存在时读取项目根目录的 `地图.png`。

## 操作

- 主菜单可开始义熙元年剧本、读取存档或退出。
- 地图支持滚轮缩放、按住左键拖动；最小比例始终铺满地图框，拖动到地图边缘后会停止。城市圆点随地图等比例缩放，单击可查看控制者、首府、城防和驻军。
- 金戈铁马四个子剧本共用龙纹主界面：顶部导航、地图上方只读阶段流程、左侧两列阶段操作、中央实时地图、右侧国势和“纪事/军事”页签、右下主菜单与存档。外框随窗口铺满，实时地图保持等比缩放。
- 左侧滚动条用于查看较多操作，“下一阶段/结束回合”固定在底部。法律、经略、决议从分类入口打开；发展阶段的地区名可以点击查看详情，方针和文化供给按钮可直接切换。
- 右侧纪事、军事各显示最新5条，历史按钮打开完整记录；切换页签不会清除记录。
- 朝堂、家族、经济、军事状态和外交状态窗口在任意阶段都能查看，同时只保留一个状态窗口。
- 存档写入 `game/saves/`，包含当前所有动态数据。

开始“金戈铁马”后会继续选择子剧本：“宋武北伐”使用1.1规则，“元嘉之治”使用1.2独立规则；随后直接进入难度选择。外部模型AI对手测试模式已经废除，游戏只使用本地AI。

战争中，军队通过行军或进攻进入敌方地区首府，会立即取得整个地区的实际控制权。议和时可定制双向割地、赔款和臣服条款；AI 必定愿意割让已被敌军实际控制的己方土地。法理所有权只会在和平协议生效后改变。

法理土地清零的政权视为灭亡，会从外交行动和外交状态列表中移除，不再执行 AI 行动或支付赔款。军队只能在本国仍受控制的首都组建；创建时以滑块选择 1–9 个营，每营固定 1000 人，编制计算器会实时显示兵力、预备役、月军饷和行动力。

陆军走水路消耗 0.3 行动力，纯骑兵走水路消耗 0.6；水军和海路消耗规则保持不变。

## 模块结构

```text
game/
├─ main.py                  程序入口
├─ resources/
│  ├─ common/config/        跨版本通用初始化模板（城市、道路、地区等）
│  ├─ common/ui/            主界面龙纹背景（dragon_frame.png）
│  └─ versions/
│     ├─ 1.1/               1.1专属配置、剧情文档及来源数据
│     └─ 1.2/               1.2配置与文档预留目录
├─ saves/                   运行时存档
├─ app/
│  ├─ models.py             游戏状态与军队模型
│  ├─ data_loader.py        配置读取、兼容修复与诊断
│  ├─ save_service.py       存读档
│  ├─ content/
│  │  ├─ v1_1/              1.1专属故事、事件、决议与经略
│  │  └─ v1_2/              1.2元嘉之治独立内容、经济与地方治理
│  ├─ rules/                无界面依赖的规则、AI和回合结算
│  └─ ui/                   菜单、地图、阶段和状态窗口
└─ tests/                   规则与数据回归测试
```

规则层不导入 Tkinter，界面只通过规则函数修改状态。因此后续增加法律、经略、事件、政党或替换 UI 时，可以独立维护。

新主界面分为 `ui/dragon_layout.py`（背景、响应式区域与导航）、`ui/sidebar_stages.py`（窄栏阶段视图）、`ui/main_screen.py`（地图和状态整合）；`stage_panels.py` 保留原有行动方法与详情对话框。
可运行 `python tools/preview_dragon_ui.py --scenario wenjiao_south --phase 1` 只读预览布局，不会读写任何玩家存档。

## 测试与数据诊断

```powershell
python -m unittest discover -s tests -v
```

当前测试配置含一条重复城市记录、若干引用缺失城市的道路、数个缺失首都，以及许多空的 `regions[].cities`。加载器会保留首条重复记录、从城市的 `region_id` 自动补全地区城市、跳过无效道路，并在 `GameState.diagnostics` 保存说明；原始 JSON 不会被修改。缺少地图坐标的城市无法凭空绘制，因此相关政权暂不创建初始驻军，补齐配置后会自动纳入。

## 当前边界

1.1保留既有法律、经略、决议和完整事件链；1.2使用独立的人口、土地、市场、物流、地方稳定/控制与军粮系统。联姻等尚无完整设计数据的功能仍待后续扩展。
