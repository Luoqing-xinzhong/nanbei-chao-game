# 1.2“元嘉之治”内容包

- `scenario.py`：422年开局、疆域、军队、党派和剧情事件。
- `story_texts.py`：读取《1.2元嘉之治_422-433》设计稿中的事件、决议长文本。
- `strategies.py`：1.2独立的31项元嘉经略、前置条件、暂停与月度完成效果。
- `decisions.py`：1.2独立的18项决议、动态人物/地区选项及执行效果。
- `events.py`：422—433事件链、架空分支、人物存活校验和事件结算。
- `economy.py`：人口单位、土地、生产消费、市场、漕运、地方治理、军粮与征兵。

此包通过 `content_version=1.2` 与1.1内容隔离。
