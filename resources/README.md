# 资源目录

```text
resources/
├─ common/
│  └─ config/       各版本共同使用的城市、道路、地区、政权、人物和家族模板
└─ versions/
   ├─ 1.1/
   │  ├─ config/    程序实际加载的1.1人物与家族覆盖配置
   │  ├─ docs/      1.1策划、剧情文档与人物说明
   │  └─ source_data/ 早期来源稿；仅供查阅，不参与程序加载
   └─ 1.2/
      ├─ config/    1号存档导出的1.2人物、地区与政权配置
      └─ docs/      1.2策划文档预留位置
```

通用模板和版本覆盖数据分开加载。不要把 `source_data` 中的早期来源稿直接覆盖到 `config`。
